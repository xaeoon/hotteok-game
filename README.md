# 🥞 호떡 가게

**손으로 하는 길거리 간식 가게 게임.** 웹캠이 손을 인식해서, 손바닥으로 반죽을 꾹 눌러 펴고 손을 뒤집어 호떡을 뒤집어요. 너무 늦게 뒤집으면 타요!



> **PC의 크롬(또는 엣지) + 웹캠**이 필요해요. 웹캠이 없어도 마우스로 즐길 수 있어요.

---

## 게임 소개

- 제한 시간 안에 **목표 금액**을 채우면 다음 단계로 올라가요. 총 **5단계**예요.
- 단계가 오를수록 손님이 늘고 인내심은 짧아지며, **새 메뉴**가 추가돼요.
- 손님이 화나서 떠나면 하트가 줄어요. 하트가 모두 없어지면 폐업이에요.
- 어떻게 장사했느냐에 따라 **엔딩이 10가지**로 갈려요.

| 단계 | 이름 | 제한시간 | 목표금액 | 새 메뉴 |
|---|---|---|---|---|
| 1 | 동네 골목 | 2:30 | 7,000원 | 🥞 호떡 |
| 2 | 시장 입구 | 2:45 | 10,000원 | 🐟 붕어빵 |
| 3 | 골목 맛집 | 3:00 | 14,000원 | 🥚 계란빵 |
| 4 | 야시장 | 3:15 | 18,000원 | 🌰 호두과자 |
| 5 | 축제 대목 | 3:30 | 23,000원 | 🥨 꽈배기 |

메뉴마다 익는 속도가 달라요. 호떡만 눌러 펴야 하고, 나머지는 올려서 뒤집어 굽기만 하면 돼요.

## 조작법

### 🖐️ 손 인식 모드

| 동작 | 하는 일 |
|---|---|
| ✊ 빈 칸에서 주먹 | 선택한 메뉴 올리기 |
| 🖐️ 반죽 위에 손바닥 올리기 (또는 카메라 쪽으로 쭉 밀기) | 꾹 눌러 펴기 (호떡) |
| 🔄 손바닥 → 손등으로 뒤집기 | 굽는 면 뒤집기 |
| ✊ 다 익은 것에서 주먹 | 손님에게 내기 (주문한 손님이 없으면 대기 접시로) |
| ✊ 탄 것에서 주먹 | 버리기 |
| 오른쪽 메뉴 아이콘에 손 올리기 | 굽는 메뉴 고르기 |

시작할 때 손바닥을 1초 정도 카메라에 보여주면 기준을 맞춰요.

### 🖱️ 마우스 모드

| 동작 | 하는 일 |
|---|---|
| 클릭 | 올리기 / 익은 것 내기 |
| 누르고 있기 | 눌러 펴기 |
| 우클릭 또는 스페이스 | 뒤집기 |
| 숫자키 1~5 | 메뉴 선택 |
| Z키 누르고 있기 | 눌러 펴기 (손 인식이 불안할 때 쓰는 보조키) |

## 팁

- 반죽 둘레의 **링이 초록색일 때** 뒤집으면 노릇노릇한 완벽한 맛이에요. 완벽하면 보너스가 붙어요.
- 주문한 손님이 없는 완성품은 **대기 접시**(최대 4개)에 올려 두세요. 그 메뉴 주문이 들어오면 자동으로 나가요.
- 손님이 기다리는 시간이 짧아질수록 팁이 줄어요.

## 잘 안 될 때

- **카메라가 안 켜져요:** 브라우저의 카메라 권한을 허용했는지 확인하세요. 주소창 왼쪽 자물쇠 아이콘에서 바꿀 수 있어요. 줌, 카카오톡 영상통화처럼 카메라를 쓰는 다른 프로그램은 닫아 주세요.
- **손이 잘 인식되지 않아요:** 손이 화면 가운데에 오게 하고, 앞에서 밝게 비춰 주세요. 카메라 화면 아래 글자(`펴짐n 접힘n`)로 현재 인식 상태를 볼 수 있어요.
- **모델 불러오기에서 멈춰요:** 손 인식 AI 모델을 인터넷에서 받아오기 때문에 인터넷 연결이 필요해요.

## 개인정보

웹캠 영상은 **서버로 전송되지 않아요.** 손 인식은 모두 내 브라우저 안에서만 처리되고, 영상은 저장되지 않아요. 브라우저에는 최고 기록과 발견한 엔딩만 저장돼요.

## 내 컴퓨터에서 실행하기

설치할 것은 없어요. `index.html`을 크롬으로 열면 돼요. 카메라가 안 켜지면 이 폴더에서 간단한 서버를 켜고 접속하세요.

```
python -m http.server 8000
```

그다음 `http://localhost:8000/` 로 접속하세요.

## 기술

- HTML / JavaScript / Canvas 한 파일로 만들었어요. 빌드 도구가 필요 없어요.
- 손 인식: [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) (손가락 마디 21개를 찾아 주는 AI 모델)
- 주먹은 손가락 둘째 마디의 굽은 각도로, 눌러 펴기는 펼친 손의 위치와 크기 변화로, 뒤집기는 손바닥/손등 방향 변화로 판정해요.
- 폰트: [Jua](https://fonts.google.com/specimen/Jua) (Google Fonts)
