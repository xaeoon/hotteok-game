🥞 호떡 가게

웹캠이 손을 인식해요. 손으로 반죽을 올리고, 꾹 눌러 펴고, 손을 뒤집어 굽는 면을 바꾸세요!
제한 시간 안에 목표 금액을 채우면 다음 단계로! 총 5단계, 단계마다 붕어빵 같은 새 메뉴가 늘어나요. 엔딩은 10가지!

✊빈 칸에서 주먹
= 반죽 올리기
🖐️반죽 위에 손바닥 올리기
(또는 쭉 밀기) = 눌러 펴기
🔄손바닥 → 손등으로 뒤집기
= 뒤집기
✊다 익은 것에서 주먹
= 손님에게 내기 / 탄 것 버리기

굽고 싶은 메뉴는 오른쪽 메뉴 아이콘에 손(커서)을 올려서 고르세요.
주문한 손님이 없는 완성품은 ✊로 대기 접시에 올려 두면, 주문이 들어올 때 자동으로 나가요.

마우스 모드: 클릭 = 올리기/내기, 누르고 있기 = 펴기, 우클릭 또는 스페이스 = 뒤집기, 숫자키 = 메뉴 선택
